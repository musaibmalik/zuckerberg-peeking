# Mark Zuckerberg peeking

The original peeking animation, with Mark Zuckerberg in the same motion.

He peeks in from the edge, ducks back to a hand, peeks again, waves, and holds up the blank sign. Timing, hover, and the sign follow the original widget from https://peeking.ybouane.com/.

Preview: `python3 -m http.server 8766 --directory dist`.

No build step. Serve the `dist/` directory.
